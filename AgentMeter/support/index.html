Open GitHub Issues ↗

Reporting a problem

Include your operating system, AgentMeter version, installation source and steps to reproduce the problem. For provider compatibility issues, include the affected Codex or Claude Code version.

Review screenshots and diagnostics before sharing them. Do not post credentials, authentication files, tokens, private conversations, source code or full terminal history. Reading issues is public; creating an issue requires a GitHub account.

Security concerns

Follow the security reporting policy for security concerns. Do not post sensitive details in public issues.
